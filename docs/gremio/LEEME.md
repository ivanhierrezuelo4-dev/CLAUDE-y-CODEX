# Gremio · Empieza aquí

1. **`GREMIO.md`**: el documento maestro. Qué es, cómo funciona, cómo se instala (PC y teléfono), cómo se adapta a cada proyecto y la lista de comprobación para el agente instalador.
2. `REGLAS.md`: las reglas resumidas.
3. `PROMPTS.md`: las plantillas de prompt por nivel.
4. `AUDITORIA.md`: qué ahorra, qué gastaba de más y qué se cambió.
5. `tablero.html`: el tablero visual. Se publica como artefacto con las capacidades `db` y `comments`.
6. `kit/`: los archivos listos para instalar (reglas de Claude y Codex, la skill, la barra de estado, `config.toml`, la plantilla de misión y las plantillas de Obsidian).
7. `mision-demo-*.json`: ejemplos del formato de una misión (la `-3` es la compacta, la recomendada).

**Frase para el agente:** «Lee `gremio/GREMIO.md`, analiza el Gremio, instálalo en este entorno, adáptalo a este proyecto con su brief y déjalo todo listo para empezar a trabajar».
